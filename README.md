# 勤益 115-2 字彙測驗練習

國立勤益科技大學（NCUT）語言中心「英檢輔導A選課資格 — 未達初級字彙測驗」的練習網站，加上英文畢業門檻的整理。手機優先、純靜態（HTML + CSS + 原生 JS），不需要建置工具、後端或外部函式庫。

> **非官方網站。** 同學自製；考點部分為推測；正式題型、及格標準與規定以[勤益語言中心公告](https://lgc.ncut.edu.tw/p/405-1029-95793,c82.php?Lang=zh-tw)為準。

## 功能

- 今日複習（間隔重複，見下方「今日複習怎麼排題」）：每天從這裡開始，到期的字優先，不夠 20 題再補新字；答錯的字隔幾題會再出一次
- 連續天數和每日目標：首頁「今天」區塊顯示連續幾天有練習、今天答了幾題（目標 20 題）、最近 7 天哪幾天有練。只要答 1 題就算當天有練（參考 Duolingo 的做法：門檻低比較容易養成習慣）
- 模擬考：預設「仿正式考卷」，照 115-2 考生回報的格式出題（見下方「正式考試題型」）；也可以「自訂」範圍、題數（20／40／100／全部）和題型（選詞＋選擇、全選擇題、全選詞填空、拼字）。一次顯示一整面，可以翻面、改答案，交卷前不顯示對錯；計時「mm:ss / 60:00」，超過 60 分鐘變紅但不會自動交卷。交卷後看分數（40 題每題 2.5 分，保留一位小數）、及格與否、分項成績和檢討
- 選詞填空練習（同第一大題）：題目洗牌後每 5 題一組，按「對答案」看結果；空著沒填的格子算答錯
- 選擇題練習（同第二大題）、拼字練習（正式考試不考拼字，只當加強記憶）、錯題本、單字卡、單字表（可搜尋）
- 配對遊戲：6 組英文配中文，計時，配錯加 1 秒，每個範圍各記最快紀錄。中文裡的英文括號（例如「敲（knock）」）會先拿掉，免得直接看到答案
- 整句翻譯：作答後（選擇題、拼字、錯題本、今日複習）、單字卡翻面後、選詞填空按「對答案」後，以及模擬考交卷後的檢討，每句都會顯示整句的中文翻譯；作答前和模擬考作答中都不會出現。考試檢討可以切換「答錯或沒寫」和「全部題目」
- 聽發音：作答後、單字卡翻面後有「🔊 聽整句」；拼字練習可勾「聽寫：先念出整句」，每題先念出句子再拼（用瀏覽器內建語音，沒有語音的瀏覽器不會顯示這些按鈕）
- 匯出／匯入紀錄：首頁最下面。匯出會下載一個 JSON 檔，裡面是這個網站所有 `ncut-` 開頭的設定和紀錄；匯入會先顯示檔案日期和題數，按「匯入」才會取代目前的紀錄
- 點字查意思：練習、單字卡、單字表、考試結果裡的句子，每個英文字都能點，跳出中文、詞性、詞形變化、用法說明、這句裡的片語，以及這個字在題庫哪一週考過；可以念出發音，也有 Yahoo 字典連結。模擬考作答中不能點；還沒作答的題目，說明裡會提到答案的那幾行會自動拿掉
- 畢業門檻說明：要不要考字彙測驗、門檻標準、115-2 場次（自動標示已結束／下一場）、申請流程、聯絡方式
- 外觀可選「自動／淺色／深色」（自動就是跟著手機或電腦的設定），介面語言可切「中文／English」。英文模式只翻介面和門檻說明；單字的中文意思、點字說明的內容本來就是給中文使用者看的，維持中文
- 練習紀錄只存在使用者自己的瀏覽器（localStorage），不收集任何個人資料

點字說明在手機上是從下方滑出的面板（點背景關閉），平板和電腦是浮在那個字旁邊的小視窗（點外面或按 Esc 關閉）。

## 單字說明資料

都在 `index.html` 的 `RAW` 下面，三個字串，一行一筆：

| 名稱 | 格式 | 內容 |
|---|---|---|
| `NOTE` | `考點字\|詞性\|說明` | 200 個考點字的用法說明（中文意思沿用 `RAW`） |
| `DICT` | `字\|原形\|詞性\|中文\|詞形\|說明` | 句子裡其他所有英文字，全部小寫；原形和字一樣就留空。`詞形` 寫「過去式」「複數」等，頁面會顯示成「crossed 是 cross 的過去式」 |
| `PHR` | `片語\|中文` | 片語要和句子裡的寫法一字不差（小寫），點到片語裡的字時才會出現 |
| `TRANS` | `題號\|整句翻譯` | 200 句的整句中文翻譯，題號就是 `RAW` 的 0 起算順序（在 `RAW` 這幾個字串之後、`/* ---------- data ---------- */` 前面）。人名保留英文，方便對照原句；原檔錯字照句意翻。這些翻譯是本站自己翻的，不是官方資料 |

詞性代號：`n v adj adv prep conj pron art aux num name place prop abbr typo`。所有格 `'s`（例如 `boy's`）會自動去查 `boy`。

換題庫時，句子裡的每個字都要有 `NOTE` 或 `DICT`。檢查方法：本機預覽打開頁面，在主控台執行

```js
DATA.flatMap(d => d.s.replace(/[{}]/g, "").match(WORD_RE)).filter(w => !wordInfo(w).zh)
```

結果是空陣列 `[]` 就代表全部都有說明。

換題庫時 `TRANS` 也要整份重寫。檢查每一句都有翻譯：

```js
DATA.filter(d => !d.tr).map(d => d.id)
```

結果是空陣列 `[]` 就代表 200 句都有翻譯。

## 正式考試題型與模擬考

官方公告沒有寫題型和及格分數。以下是 115-2 考生 2026-11-25 應考後的回報，網站上都註明「考生回報，以語言中心為準」：

- 雙面試卷，正反面題型一樣、題目不同；有多種卷別（至少 A–D 卷）。
- 每面：一、選詞填空約 5 題（給 5 個字，填進 5 個句子的空格）；二、選擇題約 15 題（一般的單句選擇填空）。
- 試場人員表示 60 分及格。

模擬考的「仿正式考卷」照這個格式：從 200 題隨機抽 40 題分成 2 面，每面 5 題選詞填空＋15 題選擇題，題號跨面連續（1–20、21–40）。程式在 `index.html` 的 `/* ---------- mock test: paper format ---------- */`：

- `buildPages()`：每 20 題一面。`formal` 每面 5＋15；`bank` 每面 4 組、每組 5 題；`mc`、`spell` 整面同一種。
- 選詞填空每個字只能用一次：把用過的字選給另一題，原本那題會清空；再點一次同一個字母可以取消。選擇題再點一次同一個選項也可以取消。
- 交卷時還有空題要連按兩次；「‹ 放棄」也要連按兩次。作答中點側邊選單或其他按鈕離開，也要再按一次同一個按鈕才會離開（畫面上方會出現提醒）。
- 分數＝答對題數 × 100 ÷ 總題數，保留一位小數；及格判斷用答對題數算（答對 × 100 ≥ 60 × 總題數），不受四捨五入影響。
- 有作答的題目寫入作答統計（答錯的進錯題本、今日複習的盒子也會動）；沒寫的題目算錯，但不寫入統計。
- 作答中不能點字查意思（`sectionHTML` 的 `tap` 參數是 `false`）。選詞填空練習可以點，畫面上 5 題還沒對答案時，說明視窗會拿掉提到這 5 個答案的那幾行（`openPop` 對每個還沒作答的題目都套用 `hideAnswer`）。

## 今日複習怎麼排題

用萊特納盒（Leitner system，Anki 這類間隔重複軟體的簡化版）。每個字在 0–5 號盒子裡，記在 `stats` 的 `b`（盒號）和 `due`（下次該複習的日期，本機時間 `YYYY-MM-DD`）：

- 答錯：回到 0 號盒，今天就到期。
- 答對：如果已經到期（或是新字），往上升一盒，`INT = [0, 1, 2, 4, 7, 14]` 天後再出現；還沒到期就答對（例如在選擇題練習裡提早遇到）不升盒，避免一天內硬背就跳過間隔。
- 所有模式（選擇題、選詞填空、拼字、錯題本、模擬考、今日複習）的作答都會更新盒子；單字卡的「會了／還不熟」和配對遊戲不會。
- 一輪 20 題：到期的字先排（盒號小的優先），不夠再補還沒練過的新字。0–2 號盒出選擇題，3–5 號盒出拼字。答錯的字插回 4 題之後再出一次，直到答對。
- 舊版留下、沒有 `b` 的紀錄一律當成今天到期。
- 「記憶程度」把 200 個字分成：還沒練過、剛開始記（0–1 盒）、有印象（2–3 盒）、記熟了（4–5 盒）。

## 中英文介面

介面文字都寫成 `L("中文", "English")`，兩種語言放在同一行。新增或修改介面文字時兩個都要寫。門檻說明頁 `vRules()` 裡有 `zh()` 和 `en()` 兩份全文，改規定時兩份都要改；`SESSIONS` 每一場也有中英文日期和教室。

題目 id 是題庫的 0 起算順序。**換學期換題庫時，要同時改 key 名稱**（例如 `ncut-1161-…`），不然舊紀錄會對到錯的題目。

## 每學期更新清單

1. 換 `RAW` 題庫，改 localStorage key 版本號，補齊 `NOTE`、`DICT`、`PHR`、`TRANS`（見「單字說明資料」）。
2. 改 `vRules()` 上方的 `SESSIONS`（場次，中英文都要）和 `CHECKED`（查核日期），重新對照語言中心公告；`vRules()` 的中文版和英文版內容都要更新。
3. 標題、說明文字、`og.png` 裡的「115-2」。
